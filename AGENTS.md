## Ticket tracking (Tracker)

Work in this repo is tracked on Tracker: https://tracker.internal.ultrahuman.com. Guide, including the Claude Code MCP setup and the auto-tracking rule: https://dex.internal.ultrahuman.com/r/ay7j43

Coding agents:
- Check whether the work has a Tracker card. If it doesn't, nudge the engineer to create one.
- If the tracker MCP (`plane`) is configured, offer to create the card for them.
- Keep the card updated through the MCP as the work moves, with progress comments and status changes.
